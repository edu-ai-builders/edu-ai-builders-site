# 关系表达组件：使用与改造

这份组件是带有城市树木示例数据的完整 HTML。下载 relation-template.html 后，在浏览器打开即可尝试。

## 保留的学习动作

读材料 → 选择两个陈述 → 判断它们的关系 → 选择合适的英语表达 → 检查反馈并修订。

## 换成自己的材料

1. 先保存一个副本。找到脚本中的 `const D =` 数据对象，观察已有的材料、卡片和反馈字段。
2. 请 AI 先解释各字段与页面的对应关系，再更换材料和相应的数据；一次只更改一部分。
3. 对每对句子人工检查：关系有原文依据吗？是否把时间先后误当作因果？是否存在不能建立该关系的例子？
4. 检查每个干扰项的反馈理由。连接表达的使用受语境、句法和文体影响，不能把一种写法当作唯一可能。
5. 打开新文件，走完选择、反馈、修订与下载流程，并检查键盘与小屏幕操作。

组件可以帮助学习者明确表达关系，但不证明某个理论已完整实现，也不证明学习效果。不要把因果关系简化为“有 A 必然有 B”。

## 数据保存

嵌入网站的预览是临时练习环境。需要保存时，使用作品中的导出操作，或独立打开后使用其浏览器本地保存。清除浏览器数据会删除本地记录。
