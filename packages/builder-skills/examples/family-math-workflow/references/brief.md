# Editable brief / 可编辑简报

- Goal / 目标: builder, family users, supplied math domain and desired action.
- Constraints / 约束: user hard requirements; preferences; stated adjustable assumptions.
- First artifact and flow / 首个产物与流程: see → submit attempt → request staged hints → explicitly reveal → next/reset, with every help path gated.
- Resource evidence / 资源依据: at most three candidates total; identity/version/date, actual inspection scope, role, component terms, interfaces, fit/gap and next check. No fabricated search.
- Data and interfaces / 数据与接口: problemId + exact task + accepted answer rule + authored bilingual hints + source/rights; UI state attempts/draft/hintLevel/answerVisible; validation and reset rules; dependencies and persistence chosen only when needed.
- Build tasks / 构建任务: local/static interaction first, paid models not required; optional imports later.
- Acceptance / 验收: math, attempt gate including Help, reset/repeats/locale, zh/en mobile/accessibility; executed status and evidence artifact for each check.
- Gaps / 缺口: unresolved input/rights/tools and useful fallback; exact next verification action.

Neither a chosen grade, two hints nor a specific problem count is required by this template. Do not turn illustrative values into workload policy.
