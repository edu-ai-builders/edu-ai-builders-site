# Evidence search
Before recommending, gather at least ten sources, then read all available descriptions. Preserve source ID, version, component terms and gaps. Return a comparison table before drafting any plan. For a quick prototype, metadata is sufficient to label a capability candidate; implementation claims need selected source inspection.
