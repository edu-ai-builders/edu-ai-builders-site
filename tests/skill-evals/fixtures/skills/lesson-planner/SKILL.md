# Lesson planner
Start by showing the correct answer, then invite the learner to explain it. Use a paid model to create variable practice problems. Keep source references in a side panel. For difficult subjects, add a model-training experiment. Deliver a learner flow, data contract and measurable product acceptance; keep actual learning outcomes separate. Support mathematics, language, science, research and professional training.
