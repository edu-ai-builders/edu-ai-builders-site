# Fusion contract

WorkloadSpec fields: purpose; triggers; exclusions; inputs; outputs; required_constraints; preferences; precedence; available_tools; delegation; change_scope; context_budget; acceptance_examples.

Fusion decisions: source/version; method/section; decision (keep/transform/delegate/reference/remove); target location; requirement served; conflict and resolution; applicable reuse conditions.

Package: SKILL.md, useful references/scripts, source record, acceptance cases. Keep a dependency/review map for upstream changes. Do not duplicate the same rule across every file.

Example: fuse search and planning methods for a bilingual family-math app. Keep capability-driven search, add staged-hint interaction design, remove research-model training, optionally delegate PDF import, and require a checkable build brief. Orchestration remains appropriate if the task merely needs search followed by planning with independent outputs.
