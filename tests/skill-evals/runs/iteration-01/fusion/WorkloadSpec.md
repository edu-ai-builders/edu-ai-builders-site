# WorkloadSpec — 家庭双语数学练习产品计划

- purpose：把重复的家长需求、题目与可核实材料转成可建设、可验收的产品计划。
- triggers：为家长设计中英双语、手机优先的儿童数学练习产品；用户要求将多个来源方法融合成自己的复用方法。
- exclusions：其他学科、成人专业训练、模型训练、直接辅导单题、仅逐个调用已有技能并独立保留结果、部署或安装。
- inputs：家长目标、孩子年龄/基础、数学主题、自有题目、来源正文或 PDF。缺孩子背景时用明确假设；缺题目时给作者原创示例并标识。
- outputs：最多三个候选的证据表、分阶段练习流程、双语移动端简报、数据契约、第一版范围、可测产品验收、学习效果假设、缺口与下一步。
- required_constraints：先让孩子尝试，再逐层提示；初版不依赖付费模型；每轮最多比较三个候选；没有 PDF 工具不得宣称已读取页面；目录摘要不能当实现证据。
- preferences：家长易懂、少字、单列手机界面；中英切换保留练习状态；正文保持精简，专门方法放 references。
- precedence：系统/安全要求 > 用户方法与硬约束 > 这份 WorkloadSpec > 来源默认值。十来源、答案优先、付费生成等来源默认值均被明确覆盖。
- available_tools：本次只有本地文件读写；无 PDF 提取器、无外部检索调用、无部署。未来运行先检查实际能力，不按来源名称推断工具存在。
- delegation：本次没有委派；独立技能不要求安装 evidence-search、lesson-planner 或 pdf-helper。以后确有提取器可直接调用，不编造工具名。
- change_scope：只写本次输出目录；来源不改、不安装、不发布、不编辑网站。
- context_budget：未指定 token 数。每次只读相关正文、候选最多三个，先产一份简明计划；来源细节按需读引用，不读取整个来源库。
- acceptance_examples：自有乘法题；提供 PDF 摘录的分数练习；只有 PDF 且无提取工具；与数学家庭产品无关的科学培训。

选择新 skill：请求需要统一选择证据、儿童交互、手机双语与实现约束，单纯先搜索再规划会保留互相冲突的默认方法。第二个请求只要求顺序运行，另交付独立步骤结果，不生成新 skill。
