# 材料与证据

每个候选记录：ID、版本、可读取部分、用途、许可、证据定位、缺口与结论范围。正文方法支持“采用该方法”；仅摘要支持“候选能力线索”。实现、效果与页面覆盖必须分别有证据。不要从 skill 描述推断某个产品已经实现相应能力。

PDF 有工具时抽样/全量范围明确，输出文件、物理页码或印刷页码口径、提取文本、公式/扫描不确定性，检查公式后才复用。没有工具时记录文件、page=unknown、text=unavailable、uncertainty=not inspected；请用户贴文本或提供自有题目。用户声称来自第 N 页的摘录记为 user-reported page N，不当成独立核实。

若已有超过三个候选：依用户主题先选最多三个供本轮比较，其余只记未评审，不在当前表加入第四个。在选择来源之前可以了解目录，但不要把未读摘要提升成经过比较的完整方法。
