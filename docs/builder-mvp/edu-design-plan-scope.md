# edu-design-plan scope — v0.1.0

状态：可用的 agent 指令包；尚未发布 npm 或托管执行。MIT，原创方法说明。

## 输入

- 产品需求、学习目标与已有资源候选。
- 目标技术栈、部署条件和可接受的依赖。

## 输出

- 最小学习流程、资源职责、数据接口和实现顺序。
- 可交给 coding agent 的开发计划与验收任务。

## 验收

- 每项依赖有必要性，替代产品不会被全部强行组合。
- 计划区分假设、待核对条件和实际运行结果。

## 使用示例

基于这些候选，先设计一个三道题、两层提示的练习页。给我接口、开发步骤和验收标准。

## 运行边界

使用当前 agent 可用的检索与文件工具。包不会自动安装第三方项目或注册 MCP。源码证据、许可观察、实际运行与教育效果分别记录；用户授权实施时可继续完成实施。仅在任务依赖缺失条件时提问。
