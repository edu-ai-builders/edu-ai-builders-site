# edu-resource-search scope — v0.1.0

状态：可用的 agent 指令包；尚未发布 npm 或托管执行。MIT，原创方法说明。

## 输入

- 产品目标、使用者、平台与必须满足的条件。
- 可用目录、候选资源或本地元数据。

## 输出

- 带来源与版本的候选清单、替代项和缺口。
- 每项资源的职责与下一步核对动作。

## 验收

- 找不到满足条件的资源时，能明确返回缺口。
- 名称、热度或关键词不被当作运行证明。

## 使用示例

我要做一个面向家长的数学练习 Web app。请比较已有产品和可复用组件，列出来源、条件与缺口。

## 运行边界

使用当前 agent 可用的检索与文件工具。包不会自动安装第三方项目或注册 MCP。源码证据、许可观察、实际运行与教育效果分别记录；用户授权实施时可继续完成实施。仅在任务依赖缺失条件时提问。
