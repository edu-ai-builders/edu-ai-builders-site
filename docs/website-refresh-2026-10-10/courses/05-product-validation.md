# 05 · 让别人完成任务，再决定要不要继续做

状态：课程草案。对象：有一个本地学习工具或课件的教师/开发者。先修：02 或 03 的可操作作品；可用原创 fraction starter。预算 240 分钟，交付产品说明、检查记录、观察与修订、继续/缩小/暂停决策。试用是待执行任务，本包没有编造参与者或结果。

学习目标：区分能打开、能完成任务与能在新题表现；设计不给提示的观察；识别断网、误操作、内容错误与维护成本；在证据有限时做下一步决定。

## 分课与步骤

### 1. 先以使用者身份体验，再写最小产品承诺（35 分钟）

前 5 分钟把[现成分数交互](../../../public/tools/fraction-bars.html)与[原创练习版](starters/fraction-lab.html)各走一次：不读源代码，只看是否知道从哪里开始、能否完成一个动作。记录一次入口或反馈差异；把同样问题用在自己的作品上。没有自己的作品时，直接用 starter 完成后续试用协议。

一页 README 写受众、解决的一步、开始方式、材料来源、版本、运行依赖、反馈是否模型生成。为分数任务规定“预测→看同宽整体→解释→新题”，不承诺提分。老师版与学生版入口分清；退出和重做任务可以找到。

练习：请一个同伴读 30 秒后复述，记录误解而非询问“是不是很喜欢”。尚无同伴时先交自查，不补写成功案例。

### 2. 检查最容易破坏承诺的条件（45 分钟）

执行 02 的正确性、键盘、窄屏、断网检查；课件做每页内容与导航检查。核对依赖许可、来源和素材是否可分享；移除真实学生资料。若考虑 Kolibri，先写单页→平台的需求差异：内容分发、用户管理、离线频道与运维；仅代码 MIT 不代表频道内容同许可。无需为本课部署平台。

阻断：数学错误、无法完成主要动作、许可未知素材待分发。将模型反馈风险通过固定审阅反馈或关掉功能缩小范围，不靠免责声明掩盖问题。

### 3. 设计一次 15 分钟任务观察（50 分钟）

优先招募成人同伴做可用性试用，不主动发送邀请；学习者自行安排。给纸面任务，不示范点击：①预测 1/3 与 1/4；②操作并解释；③不看工具比较 2/3 与 3/5。记录匿名编号、任务、是否独立、求助次数、错误与原话。观察员不把沉默解释成不理解，也不立即救援；卡住可按预设条件协助并记录。

加入一个不同整体反例与一个不含工具的新题。短暂做对属于此任务表现，不足以证明长期掌握。涉及真实学生另按机构的同意与数据要求安排，成人可用性试用不是学生效果验证。

### 4. 执行或完成可运行的试用包（50 分钟）

有参与者则执行一次，明确人数、时间与未完成项；没有参与者则完成脚本、材料、空白记录表与自查，把状态写“待试用”。不得把自查填进 participant 表。允许交付待试用包，但不得宣称用户测试通过。

### 5. 修一个问题再查一次（35 分钟）

选一个影响目标动作的问题，如提示按钮先展示答案；记录触发、修订、再检结果。参与者可再次检查原问题，但迁移题换一题。若没参与者，人工自查修订也可记录；明确其证据来源。判断问题是材料、交互、知识还是环境，不一次重写整站。

### 6. 做下一步决策（25 分钟）

填 workbook：继续（目标动作可执行且关键错误已修）、缩小（移除不可靠自动反馈）、暂停（许可/知识/运行有阻断）。写维护责任、下一轮问题和成本预算。进一步研究可考察延迟表现、对照任务与适当样本，但不是本课结论。

## 资源与许可

必需：自己的作品、模板与浏览器，无外部服务。[Kolibri](https://github.com/learningequality/kolibri) 为扩展平台比较对象，代码 MIT，内容频道单独核验。[webapp-testing](https://github.com/anthropics/skills/tree/main/skills/webapp-testing) 可选自动检查，Apache-2.0；脚本检查不能代替人的解释任务。依赖清单继承上游课程的台账。

## Rubric（四项各 0–3）

承诺与启动、运行与内容检查、观察协议与记录、修订与决策。最低 8/12 且关键阻断为零；无参与者时“观察协议”可以达到 2 分（完整可执行），3 分需真实执行记录。真实试用不保证高分：如实记录失败优于虚构全通过。

## 卡点

“对方不会用想马上教”：先记录具体位置，再按协助规则帮助。“喜欢算成功”：观察任务与解释。“单页要不要上平台”：先证明需要多用户/内容管理，再承担运维。“没有学生可测试”：先完成成人可用性和待试用包。“功能好了就发布”：本课交付本地产品包，发布权限另行处理。

下一步：可把包送同伴复核；平台/模型扩展分别重新做资源决策和评测。任何效果陈述只覆盖真实观察范围。
