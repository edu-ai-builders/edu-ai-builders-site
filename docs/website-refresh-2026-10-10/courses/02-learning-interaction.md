# 02 · 把现成可视化改成一次真正的练习

状态：课程草案。对象：想把演示变成学生能独立使用小工具的教师与开发者。先修：能保存、打开、修改 HTML 文本；不足者先学原站 vibe-coding-basics 与 web-interactions。预算 300 分钟；交付一个离线单页、内容说明、测试表与修订记录。

学习目标：区分观看与作答；让预测、操作、解释、迁移各有明确动作；判断反馈是否提前替学生完成思考；用边界值、键盘和断网检查产品。

## 分课与可执行步骤

### 1. 先用，再拆开一份工具（40 分钟）

前 5 分钟直接打开[已有分数条工具](../../../public/tools/fraction-bars.html)，试 1/2 与 2/4、1/3 与 1/4，写下“学生实际做了什么”。再打开[原创练习版](starters/fraction-lab.html)，完成一次预测与解释，选定自己的第一项改动。不要求先完成资源调研报告。

浏览原站 `/use/fraction-bars` 与对应 `public/tools/fraction-bars.html`，画出输入→状态→图形→反馈。查看公开 Math Viz Kit 了解原始设计；因本次许可不明确，只分析、不复制上游实现。复制本包 `starters/fraction-lab.html` 到自己的目录，它是原创实现。先回答“保持整体一致为什么必要”。

练习：给一个不同整体大小的静态反例，指出面积看起来更大不代表分数更大。验收：需求写的是比较分数，不能变成比较屏幕像素。

### 2. 先预测，再操作（55 分钟）

打开 starter，填写预测再提交，才显示结果。先走等值、较大、较小三种情况。给 1/3 与 1/4 写分层提示：第一级提醒相同整体，第二级追问每份大小；不要第一级直接报答案。将控件文案改成学生读得懂的语言，保留数字标签和原生 button/select。

练习：请 AI 只修改引导与提示，列出允许改的文件和验收条件；用 diff 检查有没有同时改计算。不会 diff 就保存两份文件逐段比较。

### 3. 解释与迁移（60 分钟）

为 2/3 与 3/5 写两种可能错误解释，分别设计追问。增加至少三组题，其中一组等值，一组较大分母但较小分数，一组新分子分母。新题要求先在纸上解释再打开工具；换题时重置预测与结果。解释框没有自动评判，教师依据解释 rubric 审閱；不能把填过文字算理解。

验收：学生能拿到一个尚未见过的比较任务；错误反馈指出下一步检查，支持答案复核但不假装懂得学生全部想法。

### 4. 小步改代码（65 分钟）

将 starter 的三组分数扩成自己的可选择题组，保留同宽整体。比较用交叉乘法，限制为小的正整数；若扩展负数或极大整数，另设计规则。每改一个行为运行一次，记录输入、预期、实际。练习故意把分母显示错，先靠检查表定位，再修复。

必检：1/2=2/4；1/3>1/4；2/3>3/5；0/5<1/5；5/5=1/1；非法分母 0 不进入计算。至少完成鼠标、Tab/Enter、窄屏、断网四种人工检查。不能仅凭截图宣布功能正确。

### 5. 交出去给另一个人用（50 分钟）

写 10 分钟使用说明：谁用、先做什么、何时可看提示、如何做新题。交给成人同伴，不先讲按钮位置；记录迷路、误读、卡住，修一个影响主要任务的问题。附来源/原创说明和本轮限制。

### 6. 复盘与打包（30 分钟）

提交 HTML、README、测试表、改动记录及一组迁移题。问自己：去掉动画后能否完成任务？若能，动画只是可选表征；不要为了看起来像 AI 产品增加模型请求。

## 资源与依赖

必需：现代浏览器与包内原创 starter，无第三方依赖。参考：[Math Viz Kit](https://github.com/edu-ai-builders/math-viz-kit)，公开可读但本次未观察到根 LICENSE；仅分析参考。[原站工具](../../../public/tools/fraction-bars.html)是已有本地修订副本，不擅自为其授予新许可。自动测试可选 [webapp-testing](https://github.com/anthropics/skills/tree/main/skills/webapp-testing)（Apache-2.0），需另配置 Python Playwright；本课手工路径同样可通过。

## Rubric（每项 0–3，等级定义见 01）

任务动作、数学正确、可访问与离线、证据与维护四项。最低 8/12，数学正确≥2 且五个合法边界题均正确；任何未解决的答案错误阻止试用。3 分例：不仅能运行，还记录一个诱发误解的设计并修正；3 分不是“有更多动画”。解释评判：0无解释；1只报数字；2说明同整体或交叉乘法依据；3还能处理新题与一个反例。

## 常见卡点

修改后无变化：核对保存与浏览器路径。颜色是唯一提示：加明确文字。提示一开就泄露答案：拆成先问依据、再核对。换题仍显示旧结果：重置状态。以为全自动评分：解释仍交教师审阅，明确不做自动诊断。
