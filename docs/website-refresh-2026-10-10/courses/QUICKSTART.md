# 先试一个成品，再做自己的版本

不用先看完整课程。下面的 HTML 通过本地文件在浏览器打开；如果 Codex 展示源码，使用文件管理器双击，或浏览器“打开文件”。没有安装、账号或 API 要求。

## 现在就试（5 分钟）

1. 打开[别人已经做好的分数条工具](../../../public/tools/fraction-bars.html)。先预测 1/2 与 2/4，再操作核对；接着试 1/3 与 1/4。
2. 打开[本包原创练习版](starters/fraction-lab.html)。提交预测才显示结果，写一句解释，再离开页面尝试新题。
3. 只写一句：“我想保留____，为我的学习者增加____。”例如保留同宽整体，增加学生先判断再看图的步骤。

至此再决定学哪门，不要求先交调研报告。

| 你刚体验后想做什么 | 第一课前 5 分钟 | 拆解与自己的产出 |
| --- | --- | --- |
| 找到值得复用的项目 | 01 对比两种分数流程 | 从交互、内容、数据、工作流中挑一个复用点，再查来源与许可 |
| 改成自己的练习 | 02 试一次预测→结果→解释 | 复制原创 starter，先改一句引导，再改题组 |
| 用工作流做教学材料 | 03 打开已有数学课件（仅在本地工作区 library 中提供；公开读者可用 starter）看前两页 | 指出学生动作，回看生成契约，做自己的六页稿；本地课件不发布到网站 |
| 查 AI 反馈会不会出错 | 04 先试分数任务，再跑下面一条命令 | 看逐题失败，替换为自己的题与原始输出 |
| 知道别人能不能用 | 05 对比两种 demo 的入口和反馈 | 把问题换成自己的作品，编写并执行适当的任务观察 |

04 最短运行：进入此包的 `starters/` 目录，执行 `python3 evaluate.py cases.json outputs-a.json`。Python 3 标准库即可；没有 Python 就按题号手工比对两个 JSON。A/B 都是模拟输出，不能当模型性能。

## Directory → 试用 → 课程的接入约定

资源卡第一动作是“试一下”，指向实际 demo；同时说明浏览器即可/需要安装/需要 API。第二动作是“做自己的版本”，进入带这个资源与任务的课程起步页，保留你刚试过的项目链接。没有 demo 时第一动作改成“运行步骤”，展示最短步骤、环境与费用，不伪造试用按钮。

课程起步页先呈现任务和成品，再展开拆解与许可；台账、研究与长说明放在体验之后。课程中的可复用部分必须明确：交互骨架、教学内容、数据格式或工作流规则；每一部分仍需分别核对许可和正确性。

本地现成工具可立即体验；线上 `/tools/fraction-bars.html`、`/use/fraction-bars` 与 `/directory` 本次联网抓取未成功，因此这里不宣称线上已可达或部署一致。界面接入前需在对应运行环境核验站内路径。课程原稿状态和未验证项仍以 validation.md 为准。
