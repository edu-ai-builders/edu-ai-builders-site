# 从资源到教育产品：五个可交付课程包

编写与联网核验：2026-10-10。状态：可供备课与试学的课程草案，未实际授课，未取得学习效果证据。时间为设计预算，首次配置环境另留 30–60 分钟。

## 先用 5 分钟看看已经能做什么

先在浏览器打开[现有分数条比较器](../../../public/tools/fraction-bars.html)（本地文件双击即可，无需安装）。预测 1/2 与 2/4，再调整控件核对；接着试 1/3 与 1/4。只记一句：“我想保留它的____，给自己的学习者增加____。”然后打开[原创练习 starter](starters/fraction-lab.html)，体验预测→看图→解释，比较两种流程。

从目录进入时，先打开资源的实际 demo；没有 demo 的项目显示最短运行步骤和环境要求。体验之后才进入课程：**看别人做成什么→试一个动作→拆出可复用部分→做自己的版本→检查新题表现**。不要求先读完整台账或完成三张证据卡。

[一分钟启动与课程分流](QUICKSTART.md)列出每包第一步。原站线上 demo 与 directory 本次抓取未成功，不将其标为已验证的在线一键试用；本地现成 HTML 和原创 starter 是本包可靠的文件入口。正式页面接入可用站内 `/tools/fraction-bars.html`，上线前核对实际可达性。

这组课程服务三类具体学习者：想改一份现成工具给自己班级使用的教师；能写一点网页但不知如何判断教育资源的开发者；需要把 AI 生成结果变成可检查教学材料的课程设计者。学习者可先带来一个真实问题，也可使用包内原创“同一整体下的分数比较”任务。所有必做练习不要求付费 API；调用模型与自动浏览器检查是可选扩展。

## 与现有内容的关系

原站 `app/content/courses.ts` 读取时有 7 门：vibe-coding-basics、learning-sciences-starter、personal-learning-assistant、landing-page、web-interactions、github-starter、refactor-with-ai。这组包补齐“发现→判断→复用→做产品→验证”，不替换基础课。learning-sciences-starter 可辅助写设计假设，github-starter 可辅助保存版本，landing-page 可帮助解释产品入口；完成这些课程不是新包的全部硬性先修。

原站 `app/content/resources.ts` 有数学工具、语言关系组件和教学 Skills 入口；`library/` 有对应本地源码及实验材料。本地存在、公开仓库可读、许可明确、实际运行正常是四种不同事实。[核验台账](sources-and-licenses.md)逐项记录。EduOS 与 Working Graph 不作为成熟依赖，不发布 library 内容。

本次只新增此课程目录内的文档、原创 starters 和模板。没有修改课程 TS 数据、首页、共享 CSS 或 SEO：当前无法独立确认 UI thread 的课程数据职责边界，因此使用独占文档交付。后续界面可引用 [catalog.json](catalog.json)，它位于文档目录，不被网站运行时导入。

## 贯穿式任务与证据

学习者的问题示例：“学生看到更大的分母就说分数更大，怎样让他们解释同一个整体下的比较？”01 把问题变成候选筛选条件；02 做可操作任务；03 产生教师能审阅的引导材料；04 检查反馈是否泄露答案、数学是否正确；05 观察一个人是否能完成任务并解释。换学科时保留这条链路，重新写知识正确性与迁移题。

每包交付都保留：需求、上游链接及版本、许可、改动、验证、失败、下一步。至少有一个反例、一个新题和一个取消复用的理由。点击成功是功能证据；新题作答是有限的学习表现；要宣称有效，需要另行设计研究。

## 文件与开始方式

- `starters/fraction-lab.html`：原创、无外部依赖的起点；浏览器打开即可。不收集、存储或上传回答。
- `starters/evaluate.py` 与三个 JSON 文件：原创人工构造题与模拟输出；Python 运行，不调用模型。故意保留错误让学习者定位。
- `templates/workbook.md`：需求、证据卡、许可记录、交付和试用表。
- `templates/workflow-contract.md`：用于设计练习的工作流文本，不是已安装或跨工具兼容性已验证的 Skill。
- `sources-and-licenses.md`：2026-10-10 核验依据和限制。
- `validation.md`：本次实际执行的检查与未执行内容。

首次开始：先试现成 demo，写一句想保留和想改的地方；再读 01 第 1 课。需要改文件时才复制 starter 与填写 workbook。作品不得带真实学生身份资料。成人同伴试用可先验证流程；涉及班级学生的正式试用遵守所在机构要求，另行安排。
